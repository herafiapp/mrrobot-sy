# كاشير مستر روبوت — تطبيق Flutter

تطبيق واحد للماك والآيفون والأندرويد. الأرقام بتضل على شيتات جوجل. التطبيق بس بيحكي مع ويب آب Apps Script.

## الخطة

1. ما مننقل الشيتات. منضيف ملف `apps-script/NativeApi.js` عالمشروع الحالي.
2. الملف بيفتح `doPost`: بيفحص الرقم السري الموجود، وبيرفض سعر صرف بعيد أكتر من النص عن السعر المحفوظ، وبيمرّق الكتابة من نفس مفتاح «ما تنسجل مرتين».
3. التطبيق بيعرض المعاينة (شرائح الشام، ميجا ٢٠٪، فوق/ناقص/لحال، تدوير تحت ١٠٠٠، ألوان الفرق). الحفظ بيصير على السيرفر.
4. الشاشات: بيع وباركود، شام/ميجا/USDT، دفتر الجيوب، صبح اليوم و Z، مواقيت دمشق ومنبه قبل الأذان بـ ٢٠ دقيقة.
5. صفحة المحل العامة ما انربطت بالتطبيق.

## الربط

1. انسخ `apps-script/NativeApi.js` لمشروع Apps Script كملف جديد. لا تمس `doGet`.
2. انشر ويب آب: ينفَّذ بحساب صاحب المحل. الوصول لازم يسمح للتطبيق يوصل، **بعد** ما يكون الرقم السري محطوط من وضع المالك. لا تحط الرقم ولا مفتاح Gemini جوا التطبيق.
3. جرّب أول على **نسخة** من الشيت، مو عالحي، لحد ما يكون في نشر تجريبي.
4. بالتطبيق، شاشة **ربط**: الصق رابط `/exec`، اكتب الرقم السري، واضغط «جرّب الاتصال». لازم يطلع شراء ومبيع ووسطي من الليرة اليوم.

## التشغيل

```bash
cd flutter_app
flutter pub get
flutter test
flutter run -d macos
flutter build macos
flutter build apk
flutter build ios
```

الباركود على الماك يجي من قارئ USB كإنو كيبورد، خانة الباركود جاهزة. على التلفون اكتب الرمز أو الصقه. واتساب ما بينفتح إلا بعد رقم الزبون.

بناء الماك و iOS بيصير على جهاز آبل. بناء الأندرويد بيلزمه Android SDK. هالبيئة فحصت الاختبارات والتحليل، وما بنت ملف `.app` لأن النظام لينكس.

المنبه: الشاشة بتحسب وقت الجرس (٢٠ دقيقة قبل الأذان، وتقدر تغيّرها). جدولة إشعار النظام بتتم لما يشتغل التطبيق على الماك أو التلفون؛ التجربة من زر «جرّب المنبه».
